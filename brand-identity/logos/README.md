# NAATAL STUDIO — Logos

## Fichiers disponibles

### Logo principal
- `logo.png` — Logo complet "NAATAL STUDIO" (usage principal)
- `logo.jpg` — Version alternative fond sombre

### Versions secondaires
- `Logo 2.png` — Version secondaire / variante
- `logo 3.png` — Version compacte "N" (favicon, admin, icones)
- `logo app.png` — Version pour applications mobiles et reseaux sociaux

## Regles d'utilisation

### Fond
- Toujours utiliser sur fond noir (#060606) ou tres sombre
- Ne jamais placer sur fond blanc ou clair sans adaptation

### Zone de protection
- Laisser un espace minimum egal a la hauteur du "N" tout autour du logo

### Taille minimale
- Logo complet : 80px de largeur minimum
- Icone "N" : 32px minimum

### Interdictions
- Ne pas deformer ou etirer le logo
- Ne pas pivoter le logo
- Ne pas modifier les couleurs du logo
- Ne pas ajouter d'effets (ombre portee, contour, etc.)
- Ne pas placer sur un fond qui reduit la lisibilite
